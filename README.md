## 🖥️ What this app does

cloud-code-study is a Windows app that helps you review and study the analyzed source code from the Janlaywss/cloud-code project. It is made for people who want a simple way to open and inspect the study version of that code without setting up a development tool.

Use it when you want to:

- Open the study build on a Windows PC
- Review the project output in a simple app
- Work with a local copy instead of browsing raw source files
- Keep the setup process short

## 🛠️ Common problems

### The file will not open

- Check that the download finished
- Make sure you extracted the ZIP file first
- Double-click the EXE file, not the ZIP file
- Try running the app as an administrator if Windows blocks it

### Windows says the app is blocked

- Open the file properties
- Look for an **Unblock** option
- Apply the change and try again
- If you do not see it, download the file again from the releases page

### The app opens, then closes

- Restart the app
- Check whether antivirus software removed a file
- Re-extract the ZIP file into a new folder
- Make sure all files stay together

### The screen looks too small

- Use Windows display settings
- Increase scale if needed
- Maximize the app window
- Check whether the release has a high-DPI mode
